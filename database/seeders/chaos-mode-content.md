Chaos Mode is PokéVoid's signature endgame challenge system — a set of long-form runs built around a **Champion**, a **Skill Tree**, and a branching **Battle Path** that grows more brutal as you progress. It is separate from the classic Gauntlet modes and cannot be accessed until you have made meaningful progress in the base game.

Every Chaos run starts by choosing a Champion. Your Champion determines your starting Pokémon options, the types and flavour of rewards that appear in your Skill Tree, the lore underpinning the run, and the Essences you need to invest to level them up between runs.

---

## Chaos mode variants

Chaos Mode is not a single game mode — it is a family of modes sharing the same structure but differing in length, difficulty modifiers, and win conditions. Every variant appears in the mode select screen as **[Base Name] [Tier Suffix]**.

### Base names

| Name | Description |
|------|-------------|
| **Chaos Journey** | Standard run with a shop. Closest to classic Gauntlet play. |
| **Chaos Rogue** | Draft-style start — you pick two random Pokémon to begin. No fixed starters. |
| **Chaos Void** | Journey variant that pushes to wave 1000. The longest standard run. |
| **Chaos Rogue Void** | Rogue + the 1000-wave length. Hardest long-form option. |
| **Chaos Nuzlight** | Chaos Journey with Nuzlight rules — no healing items purchasable in shops; fainted Pokémon revive at wave 10 milestones. |
| **Chaos Nuzlocke** | Chaos Journey with full Nuzlocke rules — fainted Pokémon are permanently removed from your party. |
| **Chaos Nuzlight Rogue** | Nuzlight rules with Rogue draft start. |
| **Chaos Nuzlocke Rogue** | Nuzlocke rules with Rogue draft start. |
| **Chaos Infinite** | Journey variant with a theoretical wave cap of 100,000. Effectively endless. |
| **Chaos Infinite Rogue** | Rogue variant of Chaos Infinite. |

### Tier suffixes

Each base name can appear with one of three suffixes that change the run length:

| Suffix | Wave cap | Notes |
|--------|----------|-------|
| **Abyss** (no suffix) | 500 (Journey/Rogue) or 1000 (Void) | Full-length run. |
| **Midnight** | 200 (most) or 400 (Void variants) | Mid-length. Good for learning the structure. |
| **FTL** | 100 (most) or 200 (Void variants) | Fast-to-lose / fast-to-learn. Shortest chaos runs. |

## The Battle Path

Instead of progressing wave-by-wave in a straight line, Chaos Mode places you on a **Battle Path Map** — a branching network of nodes you navigate one decision at a time. After each battle or reward, you pick which adjacent node to travel to next.

### Node types

Nodes are colour-coded and icon-labelled on the map. A full list of what you can encounter:

**Combat nodes**

| Node | Description |
|------|-------------|
| Wild Pokémon | Standard wild encounter. The most common node type. |
| Trainer Battle | Random trainer fight. |
| Rival Battle | Your run's assigned rival, appearing multiple times at increasing difficulty stages. |
| Major Boss Battle | A powerful multi-form boss that heals and changes form at low HP. Defeating it gives valuable rewards. |
| Recovery Boss | A boss that appears after a hard section, giving you a chance to stabilise. |
| Evil Team Boss | One of the game's evil team leaders (Cyrus, Ghetsis, Maxie, Archie, Lysandre, Guzma, Rose, Lusamine, Giovanni). |
| Elite Four | An Elite Four member. Appears in later path segments. |
| Champion | Champion battle. One of the toughest fixed encounters on the path. |
| Smitty Battle | A fight against Smitty. Rare and exceptionally challenging. |
| Evil Team Grunt | Weaker villain grunts. Common in early-to-mid path segments. |
| Evil Team Admin | Mid-level villain admin. Harder than grunts. |
| Challenge Boss / Rival / Champion | Enhanced versions of standard encounters found on the optional Challenge Path (see below). |

**Reward nodes**

| Node | What you get |
|------|-------------|
| General Rewards | Choose from a selection of useful battle items. |
| TM Rewards | A Technical Machine for one of your Pokémon. |
| Berry Rewards | Berry selection. |
| Mystery Node | Unknown reward — could be almost anything. |
| Glitch Piece | Glitch Pieces used to craft Glitch Items and Glitch Form Change items. |
| DNA Splicer | Lets you fuse two Pokémon together. |
| Passive Ability | Grants a passive ability to one Pokémon. |
| Type Switcher | Changes a Pokémon's primary and secondary types. |
| Ability Switcher | Swaps a Pokémon's ability for one of its alternatives. |
| Essence Reward | Adds Essences of a specific type to your collection. |
| The Collector | Trade collected Essences for curated rewards. |
| Move Upgrades | Upgrade a move with new properties — power, priority, multi-hit, type, and more. |
| Skill Points | Directly awards Skill Points for your active Skill Tree. |
| Skill Token | Awards Tree Tokens used to level up your Skill Tree. |
| Egg Voucher | Redeem for eggs in the Egg Gacha between runs. |
| Mints | Nature-modifying Mints. |
| PP Max | Maximises the PP of one move. |
| EXP Share | Grants an EXP Share modifier. |
| ΩItem Rewards | Rare permanent Omega Items. |
| ΩGOLD | Omega Gold (persistent currency). |
| Rogue / Great / Ultra / Master Ball Rewards | Rare Poké Ball selections. |
| Healing Rewards | Potions, Elixirs, and Revives. |
| Vitamins | Cheap stat boosters (Protein, Iron, Calcium, etc.). |

**Special nodes**

| Node | Description |
|------|-------------|
| Path Convergence | Branches merge back into a single required stop. |
| Draft Pokémon | Rogue variants only — adds a new Pokémon to your party. |

### Challenge Paths

At regular intervals — beginning around wave 50 and recurring every 50–75 waves — a **Challenge Path** branch becomes available. These optional routes contain enhanced boss fights, rival battles, and champion battles with increased difficulty and additional active modifiers. At the end of a successfully completed Challenge Path sits a **Challenge Reward** node offering rare items not otherwise available. Challenge Paths are always optional but consistently provide the best rewards in the run.

### Dynamic modifiers on individual battles

Some path nodes — particularly rivals, Elite Four members, and champion battles — arrive with one or more active modifiers that make that specific fight harder. These are randomly assigned and can stack. The number of simultaneous modifiers scales with how deep into the run you are.

| Modifier | Effect |
|----------|--------|
| **Nuzlocke** | All fainted Pokémon are permanently removed after this battle. |
| **Nuzlight** | No healing items available for this fight. |
| **Chaos Trainer** | The trainer's Pokémon are levelled higher than your highest-level Pokémon. |
| **Multi Legendaries** | The rival's team gains an extra legendary Pokémon. |
| **Chaos Boss** | The trainer's team has an additional boss-tier Pokémon. |
| **Inverted Types** | Type effectiveness is reversed for this battle. |
| **No Stat Boosts** | You cannot use stat-boosting moves. |
| **No Status Moves** | Status moves are banned. |
| **No Physical Moves** | Physical moves are banned. |
| **No Special Moves** | Special moves are banned. |
| **No STAB** | Same-type attack bonus is disabled. |
| **No Resistances** | Your type resistances are disabled. |
| **Trick Room** | Speed priority is reversed. |
| **No Switch** | You cannot switch Pokémon during the battle. |
| **No Initial Switch** | You cannot switch Pokémon at battle start. |
| **Auto Torment** | You cannot use the same move twice in a row. |
| **Auto Pressured** | Your Pokémon are automatically under Pressure. |
| **Legendary Nerf** | Your legendary Pokémon deal half damage. |
| **Pokémon Nerf** | Your strongest Pokémon deals half damage. |
| **Passive Ability** | Foes have their passive ability permanently active. |
| **Stat Swap** | Your ATK ↔ SPDEF and SPATK ↔ DEF are swapped. |
| **Extra Damage to Types** | Certain types receive extra damage. |

| **No Catch** | You cannot catch Pokémon in this battle. |

## Champions and Essences

Before entering a Chaos run you select a **Champion** from the champion select screen. Your choice shapes the entire run:

- You receive a **Signature Pokémon** personal to that Champion. Signature Pokémon start at Rank 1, cannot evolve normally, and can reach Rank 10 through the Skill Tree — gaining dramatically increased stats and abilities with each rank.
- The Skill Tree nodes that appear are weighted toward your Champion's types and specialties.
- The lore, dialogue, and flavour text during the run reflect your Champion's story and their struggle against the Void.

Champions are unlocked and levelled by spending **Essences** — type-specific resources earned from battles, reward nodes, Skill Tree nodes, and Essence Bundle rewards. To level up a Champion (which unlocks deeper Skill Tree content and additional starter node slots), you spend Essences matching their primary and secondary types. The cost is 100 Essences per level up to Champion Level 10, then 1,000 per level beyond that. Split between two types, a two-type Champion costs 50 of each type per level.

Champions marked as **Apollo** or **Diana** are special cases — their types shift each level, randomly assigned from the full type pool, meaning the Essence types you need for them change each time.

## The Skill Tree

The Skill Tree is the core of Chaos Mode's persistent progression. It is a web of purchasable nodes arranged in depth tiers radiating outward from a root node. The tree persists between runs and grows with investment in your Champion.

### Skill Points and Tree Tokens

There are two currencies for the Skill Tree:

**Skill Points (SP)** are spent to purchase individual nodes.

| Source | Amount | Notes |
|--------|--------|-------|
| Battle victory | 1–2 SP | 25% chance per battle |
| General Item reward node | 1–2 SP | 20% chance |
| TM reward node | 1–2 SP | 25% chance |
| Skill Point path node | Varies | Direct award from path |
| SP node in tree | Varies | The node's reward is SP itself |

**Tree Tokens (TK)** level up the tree, revealing and unlocking access to deeper nodes.

| Source | Amount | Notes |
|--------|--------|-------|
| Battle victory | 1 TK | 20% chance per battle |
| Wave milestone | 1 TK | Every 10 waves |
| Rival defeated | 1 TK | Per rival victory |
| Elite Four defeated | 1 TK | Per E4 member victory |
| Champion defeated | 3 TK | Per champion victory |
| Pokémon Add node | 1 TK | 20% chance |
| Tree Token path node | Varies | Direct award from path |
| Champion legendary encounter | 1 TK | Encountering a legendary from your Champion's pool |

### Tree levels and depth

The tree begins at **Level 1** with a maximum visible and purchasable depth of **3 nodes** from the root. Each level-up increases the depth cap:

| Tree Level | Max Depth | Tokens to next level |
|-----------|-----------|---------------------|
| 1 | 3 | 1 |
| 2 | 4 | 3 |
| 3 | 6 | 3 |
| 4 | 8 | 4 |
| 5 | 10 | 5 |
| 6 | 12 | 6 |
| 7 | 14 | 7 |
| 8 | 16 | 8 |
| 9 | 18 | 9 |
| 10 | 20 | Max level |

Nodes beyond your current max depth are hidden entirely. When you level up, newly reachable nodes appear and become purchasable (if their parent dependencies are also met).

### Node cost by rarity

| Rarity | SP cost |
|--------|---------|
| Common | 1 |
| Great | 1 |
| Ultra | 1 |
| Rogue | 3 |
| Master | 5 |
| Legendary | 7 |

### Node dependencies

Every node requires that at least one parent node in the tier above it is already unlocked. Deeper nodes may require specific combinations — some demand all listed prior nodes, others require just one. The tree shows unmet dependencies when you inspect a locked node.

### Starter nodes and Champion level

At depth 1 — the first ring around the root — the tree places your initial chooseable nodes. The number of depth-1 nodes starts at **4** and increases by 1 for each **Starter Node Upgrade** your Champion has unlocked through levelling, up to a maximum of **10 depth-1 nodes**. Each depth-1 node is always Common or Great rarity.

### What nodes can contain

The Skill Tree procedurally generates its reward nodes, seeded per Champion and run, weighted toward your Champion's types. Every type of node that can appear on the Battle Path can also appear as a Skill Tree reward, plus several that are Skill Tree-exclusive:

**Pokémon**

- **Signature Pokémon** — your Champion's personal Pokémon, available once per tree; each subsequent Rank (up to 10) is a separate deeper node. Signature Pokémon have 10 ranks, cannot evolve, and grow immensely stronger with each rank.
- **General Pokémon** — Pokémon filtered to your Champion's type affinity; you select one from a curated pool.
- **Legendary Pokémon (Forbidden Power)** — makes a specific legendary catchable for one capture attempt. The boss encounter chance for that legendary increases until it is successfully caught.

**Moves**

- **TM / XM** — teaches a move filtered to your Champion's types.
- **Move Upgrade** — applies a random upgrade to a move, or a Champion-preferred specific upgrade.
- **Specific Move Upgrade** — unlocks a particular upgrade path on a particular move.

**Abilities**

- **Passive Ability** — grants a Pokémon an additional passive ability slot.
- **Trainer Bond Ability (Limit Break)** — grants a 5% chance per stack for your Pokémon to activate a powerful named ability during battle. Stacks multiply with additional copies of the same ability.
- **Tera Ability** — grants a 5% chance per stack for a Tera-type Pokémon to activate a specific ability while Terastallised.
- **Forbidden Ability (SMITTY)** — a powerful Smitty-tier forbidden ability. Use at your own risk.
- **Party Ability Grant** — choose a free ability that applies to all Pokémon in your current party for the run.

**Stats and types**

- **Stat Boost** — permanently boosts specific stats for Pokémon matching your Champion's types. Non-matching types receive only the first stat listed.
- **Type Booster Item** — a held-item-style type amplifier.
- **Tera Type** — grants a specific Tera type.
- **Type Switcher** — changes a Pokémon's types to a specific type.

**Pokémon forms and builds**

- **Alt Build** — unlocks an alternate form for a specific Pokémon, tied to your Champion bond. Alt Builds have unique stats, abilities, move pools, and sometimes forbidden abilities. Each has a rank requirement.
- **Signature Alt Build** — an Alt Build specifically for your run's Signature Pokémon.
- **Mega Stone** — grants a Mega Stone usable by a compatible party Pokémon.
- **Dyna Mushroom** — causes a compatible Pokémon to Gigantamax during battle.
- **Glitch Form (Forbidden Glitch)** — unlocks a specific Glitch Form for use during the run. To actually transform into it, you need at least 5 Glitch Pieces and the correct Glitch Form Change item applied to the base species.

**Poké Balls**

- **Master Ball** — 1 Master Ball.
- **Void Ball** — 1 Void Ball (captures any Pokémon at or below 25% HP).
- **Type Ball** — 3 Balls of a specific type; caught Pokémon gain that type and learn compatible type moves.
- **Golden Pokéball** — grants an extra reward option when selecting post-battle rewards.
- **Rogue / Master Ball rarity select** — choose from Rogue-tier or Master-tier item pools.

**Persistent rewards**

- **Permanent Item (ΩItem)** — an Omega Item that persists between runs.
- **Omega Gold** — ΩGOLD persistent currency.
- **Egg Voucher** — an egg voucher of a specific tier for the Egg Gacha.
- **Relic Gold** — a large amount of in-run gold.

**Meta / collection**

- **Skill Points** — directly awards SP to spend elsewhere in the tree.
- **Tree Tokens** — awards TK to level up the tree; also earns Champion XP toward the next champion level.
- **Essence Bundle** — adds Essences of a specific type to your permanent collection.
- **Essence Type Weight** — increases the chance that a Normal-type Essence drop is rerolled as a specific type.
- **Catch Rate Bonus** — increases catch rate for Pokémon of specific types by a percentage.
- **Revive Boost** — increases the random revive chance for Pokémon of specific types.
- **More Fusions** — increases fusion priority for Pokémon of specific types.

**Utility**

- **Healing Items** — Revives, Elixirs, Potions.
- **Berry Selection** — various berries.
- **Ability Switcher** — swap a Pokémon's ability.
- **PP Max** — maximise a move's PP.
- **Baton** — transfer stat changes when switching.
- **General Items** — useful battle items.
- **Memory Mushroom** — relearn a forgotten move.

### Essence cost for high-rarity nodes

Master and Legendary rarity nodes require **Essences in addition to SP**. The base essence requirement is calculated from node depth:

```
base_essence = 15 + (5 × node_depth), rounded up to nearest even number
```

For a two-type Champion this splits ~50/50 between their two types. For a single-type Champion the full amount is required in that type.

Additionally:
- **Master-rarity Alt Build or Smitty Ability nodes** require a small amount of **Smitty Essence** (~1% of base).
- **Master-rarity Glitch Form or Legendary Pokémon nodes** require a small amount of **Glitch Essence** (~1% of base).
- **Legendary-rarity** versions of the above require ~3% of base in their respective special Essence.

## Run flow summary

1. Select a Champion from the champion select screen.
2. If playing a Rogue variant, draft your two starting Pokémon from a random pool. Otherwise use your caught Pokémon (Journey) or the Rogue draft.
3. Navigate the Battle Path map, choosing your route at each convergence point.
4. After battles and certain reward nodes, SP and TK accumulate. When enough TK are available, level up your Skill Tree to unlock deeper nodes.
5. When the Skill Tree becomes accessible during the run (via specific path nodes), spend SP to purchase nodes.
6. Rivals appear at fixed wave intervals, each encounter harder than the last.
7. Optional Challenge Paths branch off every ~50–75 waves — take them for harder fights and the best rewards.
8. At the final wave (100 / 200 / 500 / 1000 depending on variant and suffix), a climactic boss ends the run.
9. Essences, ΩGOLD, Champion XP, and Skill Tree progress all persist for future runs. Nothing except run-specific items is lost.
